# Copy, casing and typography

Read when writing UI text, headings, store listing or website copy. This applies to the app and to `docs/`.

- **Sentence case everywhere:** headings, labels, buttons, menu items, navigation and calls to action. Capitalize only the first word and proper names (*MajesticTab*, *YouTube*, *SoundFont*, *Bluetooth*, *Google Drive*, *PDF*).
  - *Correct:* `Continuous scroll or book-like pages`, `Download MajesticTab`, `Open app`, `Add tab`
  - *Incorrect:* `Continuous Scroll or Book-Like Pages`, `Open App`, `Add Tab`
- **No eyebrows.** No small uppercase tracked labels or kickers above a heading, and no index numbering unless the content is a sequence.
- **Write "and", not "&"** in headlines and body copy. The ampersand is for places where space is strictly limited.
- **Type:** system font for UI text. Barlow Condensed (`--font-display`) only for song titles, section titles and big numerals.
