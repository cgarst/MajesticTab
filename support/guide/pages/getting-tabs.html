You choose where your tabs come from. Files stay on your device unless you back them up or sync them.

Open files from your device

MajesticTab opens Guitar Pro files (.gp, .gp3 to .gp5, .gpx), PDFs and text tabs. To link a file to a song, select Add tab. To play a file without adding it to your library, select Open file under Tools in the library views. On the start screen of an empty library, the same action is called Open a single file. See Open file.

Open files from your cloud storage

Connect Google Drive, S3, WebDAV or iCloud to browse folders and open scores on any of your devices. Connecting is optional. You use your own account. You can also use these connections to sync your library.

Search the web for a tab

  1. On a song, select Find tab.
  2. Browse to a Guitar Pro, PDF or text file and download it.

MajesticTab adds the file to your library with the album metadata, tuning and track details filled in. Searching the web needs an internet connection.

When you search from an album, MajesticTab goes through the tracks one at a time (for example, Track 1 of 8). Select Skip to leave a track without a tab. Select Undo / re-download to replace a file you added. The browser also has an Ad blocking switch that blocks ads and trackers.

Fill in tabs for songs that have none

To search the web for a tab of each song that has none, select Tools in the library views and select Fill in missing tabs. See Fill in missing tabs.

Import a folder

To add many files at once, select Bulk import a folder of tabs on the start screen. After your library has songs, the start screen no longer appears. Then select Tools in the library views and select Bulk import. See Bulk import.

Browse classical tabs

To browse classical guitar tabs and MIDI files, select Explore classical guitar library on the start screen. After your library has songs, select Tools in the library views and select Classical tab browser. You download the archive when you first use it. MajesticTab doesn't include it. See Classical tab browser.

Restore a backup

To load a .mtbackup file, open Settings, select Library and backup and select Restore next to Restore from a backup. On the start screen, you can also select Restore a backup. See Backup and sync.
