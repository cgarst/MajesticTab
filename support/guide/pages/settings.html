Settings contains the defaults that MajesticTab starts from, plus your library and backup tools. Some options only appear in the apps.

Open Settings

Select Settings in the library navigation. Settings has these sections: Library and backup, Player, Appearance, Reading, Controls, Sound, Classical tab, Updates and About. The apps also have Web search.

In the reader, View and Guitar override some of these defaults for the song that is open.

Library and backup

Hide songs without tabs
Shows only songs that have at least one tab.
Sync
Keeps this device and your backup location matching. See Backup and sync.
Create a backup
Saves everything to a file, a folder or your cloud. Select Create.
Restore from a backup
Brings a backup or snapshot back. Select Restore.
Reload library metadata
Refreshes covers, durations and album details. Select Reload.
Orphaned files
Finds stored tabs that no library song uses. Select Review.
Clear cached data
Clears covers and downloads that MajesticTab keeps only to load faster. Select Clear.
Delete all data
Removes your library, setlists and settings from this device. Select Delete. Make a backup first.

Player

Preferred instrument
Choose Guitar or Bass. This sets the instrument that MajesticTab assumes.
Left-handed guitar
Flips the fretboard and the chord diagrams for a left-handed guitar.
Stringing
Standard puts the high string on top, as in tab. Upside down puts the low string on top.
Default strings
For guitar, choose From file, 7 or 8. For bass, choose From file, 5 or 6. From file keeps the string count that the tab was saved with.

Appearance

Under App theme, choose one of nine themes: Slate Blue, Mystic Dream, Blue Pearl, Cerulean Paradise, Dark Side, Ember Glow, Purple Nebula, Red Nebula or Snow White.

Reading

A new tab opens as
Choose Page or Scroll separately for Guitar Pro, PDF and text files.
Notation
Choose Tab only or Tab and standard for a new tab. To change it for one song, use View.
Reset these defaults
Select Reset to return to Scroll for Guitar Pro and text files, Page for PDFs, and string counts from the file.
Minimum section size
Choose 1 bar, 2 bars, 4 bars or 8 bars. MajesticTab joins shorter labeled sections with adjacent parts.

Size, paper and the pages shown are in the reader's View menu, not in Settings.

Controls

Shows what each key, foot pedal or controller button does. See Keyboard shortcuts and Foot pedals and game controllers.

Web search

In the apps, Block ads and trackers turns on ad blocking for the in-app browser. When you turn it on, MajesticTab downloads community rules. Select Refresh list to download them again.

Sound

SoundFonts
Select Add to add a SoundFont and Edit to change the list. Enabled SoundFonts layer from top to bottom, and lower ones override higher ones.
Strict instrument matching
Tracks that the enabled SoundFonts lack stay silent, instead of playing the closest instrument.
Force one preset
Plays every instrument except drums with a single preset from one SoundFont. The default is Off (use each track's instrument).

Classical tab

Manages the Classtab archive for the classical tab browser. After you download the archive, this section shows its size and how many pieces and composers it holds. Select Update archive to download it again, or Remove to delete it. Songs that you added to your library stay. The archive isn't part of your backup, so you can download it again at any time.

Updates

This section appears in versions that update themselves. Under Update channel, choose None, Canary or Stable. None turns automatic checks off. Canary gets early builds. Select Check next to Check for updates to look for a newer version now.

About

The About section has these rows:

  • User guide opens this guide.
  • Privacy policy opens the privacy policy.
  • Support opens the issue tracker, where you can report a problem or ask for a feature.
  • Quit closes MajesticTab in versions that can quit.
