The chord library shows chord voicings that match your strings, tuning and capo.

Open the chord library

  • In the library, select Tools and then Chord library.
  • In the reader, select Tools and then Chord library, or press C.

Match the chords to your guitar

The chord library uses the number of strings, the tuning and the capo that you set for the guitar in your hands. If you use 7 strings, a capo or a lower tuning, the chord diagrams change to match. In the Tools view, the row shows these settings. See Fit a tab to your guitar.

Find a chord

Use Chord view mode to choose how the chords are listed:

  • Every chord type lists the chord types.
  • Movable Shapes shows shapes that you can move along the neck. Each shape is drawn from its lowest fret.
  • By Note shows the fingerings for the chord on the root note that you select. Select Prefer movable shapes to place movable shapes on that root instead.

Select a root with Root note. Each chord type shows as a tile, and you can step through its shapes with the arrows. If no chord fits your filters, you see No chords match these filters.

Change the diagram style

Use Diagram orientation to choose Vertical diagrams (the traditional chord chart) or Horizontal diagrams (fretboard style).

Hear a chord

Select a chord name or its diagram to hear the chord strummed on a synthesized acoustic guitar.
