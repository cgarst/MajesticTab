MajesticTab runs on iPhone, iPad, Mac, Windows, Android, Linux and Steam Deck. After you install it, it works offline. Direct downloads are on the latest release page.

Install on iPhone and iPad

Get MajesticTab from the App Store. One purchase unlocks the app on iPhone, iPad and Mac.

If you would rather not use the App Store, you have two options:

  • Build it yourself. MajesticTab is open source. The build steps for iOS are in CONTRIBUTING.md. You need a Mac with Xcode, and you sign the app for your own device with your own Apple ID.
  • Use the web app at majestictab.zathu.net/app. In Safari, choose Share, then Add to Home Screen. The web app has fewer features than the app:
    • Browser storage is temporary. Your system can clear tabs and map points saved in the browser when storage is low or browsing data is cleared. The app has permanent offline storage.
    • No local Jam hosting.
    • No backing track separation.
    • No secure credential store.
    • No iCloud sync for Apple devices.

Install on Mac

Choose one of these:

  • Get MajesticTab from the Mac App Store. It's the same purchase as the iPhone and iPad app.
  • Download a free .dmg file from the release page. There is one for Apple silicon and one for Intel Macs.

Install on Windows

Choose one of these:

  • Get MajesticTab from the Microsoft Store. It's free.
  • Download the installer (.exe) from the release page. There is one for x86_64 PCs and one for ARM64 PCs.

Install on Android

Choose one of these:

  • Get MajesticTab from Google Play. It's free.
  • Download the .apk file from the release page and open it.

F-Droid isn't available yet.

Install on Linux and Steam Deck

MajesticTab is a Flatpak for x86_64 and ARM64. The easiest way to install it, and to get updates, is the Zathu Flatpak repository. To add it, follow these steps:

  1. Download zathu.flatpakrepo.
  2. Open the file with KDE Discover or GNOME Software, and then confirm that you want to add the Zathu Software source.
  3. Search for MajesticTab and install it.

To use a terminal instead, run the following commands:

flatpak remote-add --user --if-not-exists zathu https://flatpak.zathu.net/zathu.flatpakrepo
flatpak install --user zathu net.zathu.majestictab

The first install also downloads the GNOME runtime from Flathub. Your software center, or flatpak update, then keeps MajesticTab up to date.

You can also install a single file. Download the file for your processor from the release page. Then run the following command. Replace FILE with the name of the file you downloaded. A file you install this way doesn't update itself:

flatpak install --user FILE

On a Steam Deck, run the command in Desktop Mode. MajesticTab supports the Deck's controls. See Foot pedals and game controllers.

Update the app

Store versions update through the store. Versions that update themselves have an Updates section in Settings. To check for an update, follow these steps:

  1. Select Settings in the library navigation and then select Updates.
  2. Under Update channel, choose Stable, Canary or None.
  3. Next to Check for updates, select Check.

Cost

MajesticTab is open source. It's free on the Microsoft Store, Google Play, Linux and direct downloads. On the Apple App Store, a one-time purchase unlocks the app on iPhone, iPad and Mac. MajesticTab has no subscriptions, ads or accounts.
