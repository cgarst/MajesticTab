Bulk import adds many files at once. You choose a folder, and MajesticTab pairs each file with a song. You review the pairings before anything is imported.

Open Bulk import

In the library, select Tools and then Bulk import. On the start screen of an empty library, select Bulk import a folder of tabs.

Importing a folder needs the MajesticTab app on a computer, or the Chrome or Edge browser. On a phone, add tabs to a song one at a time.

Import a folder of tabs

  1. Select Tabs at the top of the page.
  2. Select Choose folder and choose the folder. MajesticTab includes subfolders.
  3. Under Pair by, choose how your files are named. See the next section.
  4. Review the list. Each row shows the song that the file is paired with. Clear the check box on a file to leave it out.
  5. Select Import.

MajesticTab reads Guitar Pro, PDF and text files. If the folder has none, you see No Guitar Pro, PDF or text files were found in that folder.

Choose how files are named

Under Pair by, choose one of these:

  • Automatic picks the best reading for each file.
  • Artist - Song reads names like Artist - Song.gp5.
  • Artist/Album/Song reads folders like Artist/Album/03 Song.gp5. A track number before the song is ignored.

Automatic can also use the title, artist and album written inside a Guitar Pro file. PDF and text files don't carry that information.

Fix a pairing

MajesticTab looks each pairing up in your library and then on MusicBrainz. The rows fill in while the lookups run. You can change any row:

  • Select Search to find the song or album on MusicBrainz.
  • Select Use as custom music to import the file under the names you type.
  • Clear the check box to leave the file out.

Use the switch Import files with no good match as custom music to save songs that MusicBrainz can't find, or only guesses at, under the names from the file.

Import a tab book

A PDF that is a whole album's tab book can be paired with an album instead of a song. For each file, choose One song or A whole album's tab book under This file is. If the album isn't on MusicBrainz, select Use as custom album tab.

Skip songs that have a tab

The switch Skip songs and albums that already have a tab leaves out a file when its song, or its album's tab book, already has a tab. To import that file anyway, check its row.

Import audio files

Select Audio files at the top of the page to match a folder of audio files to songs that are already in your library and have a tab. This mode doesn't look anything up on MusicBrainz and doesn't create songs. A file with no matching song is left out.

Under The files are, choose what each file becomes:

  • Automatic makes each file the song's original recording, unless its name says "backing track" or "no guitar". Then it becomes the backing track.
  • Recordings of the songs makes every file the song's original recording.
  • Backing tracks makes every file the song's backing track.

If a match is a guess, check it. To pick a different song, use Search your library for this song. On a phone, add audio to a song from its Sound panel instead.
