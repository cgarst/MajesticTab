Open file plays a tab without adding it to your library.

Open a file

  1. In the library, select Tools and then Open file. On the start screen of an empty library, select Open a single file.
  2. Select Browse files and choose a file. In the web app and on Mac and Windows you can also drop a tab file on the page.

The page opens Guitar Pro files, PDFs and text tabs. See Supported files.

Search the web for a tab

Enter a song in the search field Search the web for a tab… and select Search. Searching the web needs an internet connection.

Open a file from cloud storage

Under Or open from, select a storage provider that you connected, such as Google Drive, S3, WebDAV or iCloud, to browse its folders. See Getting tabs in.

Keep the tab

To add the open tab to your library, open the song menu in the reader and select Save to library.
