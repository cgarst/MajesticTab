Fill in missing tabs lists the songs in your library that have no tab, and fills them in: automatically from a search provider that can fetch files, and with a guided search in your web browser for the rest.

Check what you need

This tool is in the MajesticTab apps for Windows, macOS, Linux, Android and iOS. On the web, you add tabs to a song one at a time. See Getting tabs in.

The tool uses the search providers in Settings. A provider is either a web page, which opens in your browser, or a service that gives MajesticTab the file itself. MajesticTab tells them apart on its own. Providers are tried in the order you list them.

Search all

If a search provider is a service that fetches files, Search all goes through the list on its own, one song after another. You can leave the page while it runs. It shows how many songs are done and what it is fetching now, and Stop ends it.

  1. In the library, select Tools and then Fill in missing tabs.
  2. To work on one artist, choose the artist in Artist. The default is All artists.
  3. Select Search and the number of songs.

The arrow beside Search, on the page and on each song, lists every search provider. Pick one to use only that provider this time: a service that fetches files is asked for every song, and a web provider starts the browser walkthrough. The button itself uses your default.

When it finishes, each song is Added, Not found, Needs a pick or failed. A song a provider has no tab for goes on to the next provider. When a service finds several matches and none is plainly the song, the song waits, and Choose matches lets you pick from the list afterwards. If the service cannot be reached, or refuses your access token, the run stops and says why. Songs it did not find are remembered, so the next run skips them until you select Search not found again.

Search in your browser

For songs no provider could fetch, select Continue in your browser. MajesticTab shows one song at a time.

  1. Select Open search. The search opens in your web browser. With more than one web provider, choose which in Search with.
  2. Download the tab file.
  3. Open the file with MajesticTab, drop it on the page, or select Choose file. You can also select Paste link and give the address of the file.

A service that sends the file back with a majestictab:// link carrying url= and the address of the file is handled the same way: while the page is waiting, the file goes to that song.

MajesticTab adds the file to the song, whatever its format, and moves on to the next one. Skip leaves a song for later and Previous goes back. Files you open are only added to the song while the page is waiting for a tab.

One song

Select Search on a song to search for just that one, or use its arrow to choose another provider. The page shows how many songs have no tab. If every song has one, you see Every song in your library has a tab.

To copy or save the list of songs, select Copy list or Export list.
