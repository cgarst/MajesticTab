In a Jam, one player hosts a session on the local network and the other players join from their own devices. Playback stays in sync, so everyone plays the same bar.

Host a session

  1. Connect every device to the same network.
  2. Open Tools, select Jam mode, and then select Host a jam.
  3. Share the host address. Each address has a copy button and a QR code.
  4. Open a song. It opens for every player.

Every MajesticTab app except the web version can host. To end the session, select Stop hosting. To remove one player, select Kick. A session holds up to 32 players.

Join a session

Open Tools, select Jam mode, and then select Join a jam. Scan the host's QR code or enter the host address. A player without the app can open the host address in a browser.

What stays in sync

  • Playback position.
  • The host's YouTube video, including its map points.
  • The song. Guitar Pro, PDF and text tabs all open for every player.
  • The host's mixer settings and SoundFonts. A guest's device uses them during the session and returns to its own settings when the guest leaves.

Assign tracks

The host can assign each guitarist a part. A player can hear only their assigned tracks, or only the backing tracks. The host can also mute audio on guests, or mute assigned tracks for players who have no assignment.

Know the limits

  • A Jam works on a local network. It doesn't work over the internet.
  • The host doesn't share local audio files. Guests hear the host's YouTube video or the synth.
