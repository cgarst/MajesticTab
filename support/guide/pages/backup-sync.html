Your library is stored on your device. You can save a copy to one file, or keep your devices in sync through cloud storage that you own.

Back up your library

  1. Select Settings in the library navigation and then select Data management.
  2. Next to Create a backup, select Create.
  3. Check the file name, then select Back up.

The backup is one .mtbackup file that MajesticTab saves on your device. To save it somewhere else, such as Google Drive, an S3 bucket or a WebDAV server, select Save somewhere else before you select Back up. The screen also shows when you last made a backup on this device.

The file holds your library, setlists, settings and SoundFonts. Each song is stored as a standard .mpak file inside it, with its tabs, the recordings you saved with it and their map points. A backup does not depend on your sync service, and it is a good copy to keep before you change anything large.

Restore a backup

  1. In Data management, next to Restore from a backup, select Restore. On the start screen of an empty library, you can also select Restore a backup.
  2. Choose a .mtbackup file (in the web app and on Mac and Windows you can also drop one on the screen). MajesticTab shows how many songs, setlists and SoundFonts it holds and when it was made.
  3. Choose how to restore it, then select Restore backup:
    • Add missing items keeps everything you have and adds what the backup has and you lack. Songs that are already in your library are left as they are.
    • Replace all data erases your stored tabs, library, settings and audio files first, and replaces them with the backup. Tick the box to confirm.

If a file is damaged or incomplete, MajesticTab restores what it can and tells you how many files were missing.

Backups made by earlier versions of MajesticTab still restore. Snapshots that an earlier version saved to Google Drive, an S3 bucket, a WebDAV server or a backup folder are on the same screen, under the file picker.

Sync your library across devices

In Cloud sync under Cloud storage, next to Sync with cloud storage, select Sync and choose one of these locations:

  • Google Drive
  • iCloud Drive
  • S3 bucket
  • WebDAV server
  • A folder on this device

MajesticTab compares this device with the sync location and lists what it will receive, send, combine or remove. Select Sync now to apply the changes. Songs, recordings, collections, recents, setlists, SoundFonts and settings (including web search sources) stay in step across your devices.

By default, sync keeps your song list and settings in step while leaving files in your sync location until you open a song (pinned songs and songs in setlists still download right away). Turn on Keep all files on device before syncing to download every song in your library onto this device. To clear copies already on this device when keeping files in the cloud, select Remove local files already in Drive (or your sync location).

To overwrite the sync location with what is on this device, select the Replace action in the sync header (such as Replace Drive or Replace bucket) and confirm. This sends everything from this device and removes anything in the sync location that isn't on this device.

Turn on Auto-sync cloud storage to keep your library synced in the background whenever a location is connected. While a background sync runs, a thin progress bar appears along the top edge of the app alongside a brief notification when it starts. If auto-sync pauses for sign-in, folder access or review, a notification lets you open Sync directly; while you are playing or in Reading mode, notifications wait until you stop.

MajesticTab uses your own account or folder. Sync is optional.

Export your library

To export your library as a spreadsheet, your map points, your original tab files or printable PDFs, select Tools in the library views and then select Bulk export. See Bulk export. To export one tab as a PDF, open the song menu and select Export as PDF.

Manage stored data

Data management also contains these rows:

  • Reload library metadata refreshes covers, durations and album details.
  • Orphaned files finds stored tabs that no library song uses.
  • Clear cached data clears covers and downloads that MajesticTab keeps only to load faster.
  • Delete all data removes your library, setlists and settings from this device. Make a backup first.
In the web version, the browser stores your data and can clear it. MajesticTab warns you that browser storage is temporary. Make backups, or use cloud sync.
