Your library is stored on your device. You can save a copy to one file, or keep your devices in sync through cloud storage that you own.

Back up your library

  1. Select Settings in the library navigation and then select Library and backup.
  2. Next to Create a backup, select Create.
  3. Choose where to save the backup: a file, a folder or your cloud.

The backup is one .mtbackup file that contains your library, settings and SoundFonts. Audio files that you linked to tabs are included unless you turn that off.

Restore a backup

In Library and backup, next to Restore from a backup, select Restore. Then choose your backup. On the start screen of an empty library, you can also select Restore a backup.

Sync your library across devices

In Library and backup, next to Sync, select Sync and connect one of these services:

  • Google Drive
  • S3
  • WebDAV
  • iCloud

MajesticTab uses your own account on the service. Sync is optional.

Export your library

To export your library as a spreadsheet, your sync points, your original tab files or printable PDFs, select Tools in the library views and then select Bulk export. See Bulk export. To export one tab as a PDF, open the song menu and select Export as PDF.

Manage stored data

Library and backup also contains these rows:

  • Reload library metadata refreshes covers, durations and album details.
  • Orphaned files finds stored tabs that no library song uses.
  • Clear cached data clears covers and downloads that MajesticTab keeps only to load faster.
  • Delete all data removes your library, setlists and settings from this device. Make a backup first.
In the web version, the browser stores your data and can clear it. MajesticTab warns you that browser storage is temporary. Make backups, or use cloud sync.
