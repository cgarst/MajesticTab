Make backing tracks takes audio files you've added to your songs and uses StemDeck to remove the guitar. MajesticTab saves the result as the song's backing track.

Check what you need

  • The MajesticTab app. The web version doesn't have this tool.
  • The StemDeck app, running on your computer.
  • At least one song with a local audio file. To add one, open a song's Sound panel, select Original and select Add audio file.

Start a batch

  1. Start StemDeck.
  2. In the library, select Tools and then Make backing tracks.
  3. Select the songs you want. Use Select all or Select none to change the whole list.
  4. Select Make backing tracks.

MajesticTab sends one file at a time. Each song shows its progress, for example Waiting in StemDeck and then Backing track added. Leaving the Tools view doesn't stop the batch. When you open the page again, it shows where the batch is.

To play the result, open the song, open Sound and switch from Recording to Backing.

Replace existing backing tracks

Songs that already have a backing track are hidden from the list. To include them, select Include songs that already have a backing track. The new track becomes the default, and MajesticTab keeps the old one.

Connect to StemDeck

On a desktop, MajesticTab looks for StemDeck on your computer by itself. If it can't find it, you see StemDeck is not running on your computer. Start StemDeck and select Check again.

On a phone, enter the address of the computer that runs StemDeck in the StemDeck address field. StemDeck shows its port on its Settings, Network page.
