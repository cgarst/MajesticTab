Fill in missing tabs

Fill in missing tabs walks through the songs in your library that have no tab. For each song, it opens a web search for a tab.

Check what you need

This tool is in the MajesticTab apps for Windows, macOS, Linux, Android and iOS. On the web, you add tabs to a song one at a time. See Getting tabs in.

Fill in missing tabs

  1. In the library, select Tools and then Fill in missing tabs.
  2. To work on one artist, choose the artist in Artist. The default is All artists.
  3. Select the start button. It shows how many songs it will cover, for example Start with 12 songs.
  4. In the browser that opens, find a tab for the song and save it.

When you save a tab, the search for the next song opens. Select Skip to leave a song for later. The tool takes songs in order by artist, album and track.

The page shows how many songs have no tab. If every song has one, you see Every song in your library has a tab.

Search for a single song

If the page lists your songs, select Search on a song to search the web for it.
