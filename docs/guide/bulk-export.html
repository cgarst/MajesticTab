Bulk export

Bulk export saves your whole library in one of four forms: a spreadsheet, your sync points, your original tab files or printable PDFs.

Open Bulk export

In the library, select Tools and then Bulk export.

Export your library

  1. Under Bulk export modes, choose a mode.
  2. Select the export button for that mode.
  3. When the export is ready, select Save / Share to save or share the file.

While an export runs, the page shows its progress. Select Cancel to stop it.

Choose a mode

Library metadata
Select Export metadata as CSV. The CSV spreadsheet has these columns: artist, album, song, YouTube URL, YouTube backing URL, tunings, tab files and year.
Sync data
Select Export sync data as ZIP. The ZIP has one JSON file for each song and recording, in artist and album folders. Each file names the YouTube video or audio file that the sync points belong to.
Original tab files
Select Export original tabs as ZIP. The ZIP has the .gp, .pdf and .txt files from your library and storage. Select Include unlinked tab files from storage to add files that no song uses. They go in an Unsorted folder.
PDF export
Select Export all tabs as PDF (ZIP). MajesticTab lays out every tab in your library and exports each as a printable A4 PDF. The ZIP has artist and album folders.

If your library has nothing to export, you see a message such as No tab files found.
