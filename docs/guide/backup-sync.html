Backup and sync

Your library is stored on your device. You can save a copy to one file, or keep your devices in sync through cloud storage that you own.

Back up your library

  1. Select Settings in the library navigation and then select Library and backup.
  2. Next to Create a backup, select Create.
  3. Check the file name, then select Back up.

The backup is one .mtbackup file that MajesticTab saves on your device. To save it somewhere else, such as Google Drive, an S3 bucket or a WebDAV server, select Save somewhere else before you select Back up. The screen also shows when you last made a backup on this device.

The file holds your library, setlists, settings and SoundFonts. Each song is stored as a standard .mpak file inside it, with its tabs, the recordings you saved with it and their sync points. A backup does not depend on your sync service, and it is a good copy to keep before you change anything large.

Restore a backup

  1. In Library and backup, next to Restore from a backup, select Restore. On the start screen of an empty library, you can also select Restore a backup.
  2. Choose a .mtbackup file, or drop one on the screen. MajesticTab shows how many songs, setlists and SoundFonts it holds and when it was made.
  3. Choose how to restore it, then select Restore backup:
    • Add missing items keeps everything you have and adds what the backup has and you lack. Songs that are already in your library are left as they are.
    • Replace all data erases your stored tabs, library, settings and audio files first, and replaces them with the backup. Tick the box to confirm.

If a file is damaged or incomplete, MajesticTab restores what it can and tells you how many files were missing.

Backups made by earlier versions of MajesticTab still restore. Snapshots that an earlier version saved to Google Drive, an S3 bucket, a WebDAV server or a backup folder are on the same screen, under the file picker.

Sync your library across devices

In Library and backup, next to Sync, select Sync and connect one of these services:

  • Google Drive
  • S3
  • WebDAV
  • iCloud

MajesticTab uses your own account on the service. Sync is optional.

Export your library

To export your library as a spreadsheet, your sync points, your original tab files or printable PDFs, select Tools in the library views and then select Bulk export. See Bulk export. To export one tab as a PDF, open the song menu and select Export as PDF.

Manage stored data

Library and backup also contains these rows:

  • Reload library metadata refreshes covers, durations and album details.
  • Orphaned files finds stored tabs that no library song uses.
  • Clear cached data clears covers and downloads that MajesticTab keeps only to load faster.
  • Delete all data removes your library, setlists and settings from this device. Make a backup first.
In the web version, the browser stores your data and can clear it. MajesticTab warns you that browser storage is temporary. Make backups, or use cloud sync.
