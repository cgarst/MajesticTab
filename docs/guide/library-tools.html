The Tools view

The Tools view in the library lists every tool in one place: music reference, practice tools, tools for adding tabs, and tools for managing your library. Select a tool to open it.

Open the Tools view

In the library views at the top, select Tools. On a wide screen, the tool you select opens next to the list. On a phone, it replaces the list.

The reader has its own Tools menu for the reference tools, the tuner, the metronome and Jam. See Fretboard and the Tools menu.

Find a tool

The list groups tools by purpose:

Reference
Chord library, Scales and Circle of fifths.
Practice
Tuner, Metronome and Jam.
Getting tabs
Open file, Classical tab browser and Fill in missing tabs.
Library
Bulk import and Bulk export.

Some rows show a short note about the current state on the right. For example, Metronome shows the tempo, Classical tab browser shows how many pieces are installed, and Fill in missing tabs shows how many songs have no tab.

Check which tools your version has

  • Fill in missing tabs is in the MajesticTab apps. The web version doesn't have it.
  • Jam appears only in the apps. The web version doesn't show it, but a browser can open a host's address to join. See Jam sessions.
