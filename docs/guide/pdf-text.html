PDF and text tabs

PDF and text tabs have their own reading tools. Many practice features work for them as they do for Guitar Pro tabs.

Condense a PDF

Multi-track Guitar Pro PDF exports often contain empty staves and wide margins. To remove them, turn on Condense PDF in the song menu. The option is marked Experimental.

Bookmark pages

In the song menu, select Bookmark Current Page to mark the page you're on. Select Bookmarks & Table of Contents to jump to your bookmarks or to the PDF's outline.

Split a book into songs

If one PDF contains a whole book, you can create songs from page ranges of it.

  1. Open the album that the book belongs to.
  2. Select Add book and choose where the PDF comes from.
  3. Select Set book pages and set the pages of each song.

Turn pages

PDF and text tabs have a page strip where Guitar Pro tabs have the bar ruler. You can turn pages by selecting either side of the page, with the arrow keys, or with a foot pedal. See The reader.

Map to a recording

You can map PDF and text tabs to a recording in the same way as Guitar Pro tabs. A recording bar shows the time and map state above the page strip. See Original recording.

Export as PDF

To export one tab, select Export as PDF in the song menu. To export your whole library, see Backup and sync.
