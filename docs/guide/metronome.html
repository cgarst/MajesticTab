Metronome

The metronome keeps time at any tempo. It has a tempo display, tap tempo and time signatures.

Start the metronome

  1. Open the metronome. In the library, select Tools and then Metronome. In the reader, select Tools and then Metronome, or press M.
  2. Set the tempo. Select − or +, type digits, or use the arrow keys. Hold Shift with the arrow keys to change the tempo in steps of 10.
  3. Select Start. To start or stop from a keyboard, press Space.

Set the tempo by tapping

Select Tap tempo in time with the music. On a keyboard, press T.

Change the time signature

Use Time signature and how many bars to play it to set a time signature and how long it lasts. Select Add another time signature to play a sequence of them. Select Reset to 4/4 to start again.

Change how the click shows

  • Mute the click keeps the display and silences the sound. From a keyboard, press M.
  • Blink on the beat flashes the dot above the arm.

Use the metronome while you practice

The Metronome and Count-in switches in Practice are separate from this tool. See Practice.
