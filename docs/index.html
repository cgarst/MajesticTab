Questions

Is it really free?

Yes. Every feature is free: no paid tier, no subscription, no ads and no trial clock. The code is open source on GitHub.

Does it work offline?

Yes. It is a native app, and the built-in synth plays tabs with no connection. YouTube backing tracks, web search and cloud sync need internet, and you choose whether to use them.

Which files can I open?

Guitar Pro files (.gp, .gp3 to .gp5, .gpx), PDFs and text tabs, from your device or from Google Drive, S3 or iCloud.

Where are my tabs kept?

On your device, unless you choose to back them up or sync them. One .mtbackup file holds your library, settings and SoundFonts, so moving to a new device takes one restore.

Can I jam with friends?

Yes, on the same network. Anyone can join a Jam for free. Hosting needs a native app, and it is a feature in the App Store, Google Play and Microsoft Store versions.

Does it run on my device?

iPhone, iPad, Mac, Windows, Android, Linux and Steam Deck. Downloads are below, with the store listings that are open today.
